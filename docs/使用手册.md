# 使用手册（运行 / 参数 / 排错）

## 1. 环境准备（新机器只做一次）

```powershell
cd "<工程根目录>"
python -m pip install -r app\requirements.txt
```

`python` 找不到就先跑 `python_path.txt`：在工程根目录新建这个文件，里面只写一行 `python.exe` 的完整路径。`scripts\run_daily.bat` 会优先用它，其次自动找 `E:\Python313`、`%LOCALAPPDATA%\Programs\Python\Python312\Python311`。

## 2. 日常运行

根目录两个入口，双击即可：

| 入口 | 行为 |
| --- | --- |
| `测试运行.bat` | 跑一次并**保存 Excel**，结束后窗口停住显示退出码 + 输出目录，适合验数据 |
| `定时任务启动.bat` | 拉起常驻调度器（最小化窗口），到点自动跑，**不保存 Excel、只覆盖飞书在线表格**；一直挂着，关窗口即停 |

带参数（在命令行里写）：

```powershell
.\测试运行.bat --verify             # 只验证登录
.\测试运行.bat --no-feishu          # 只出本地 Excel，不动飞书
.\定时任务启动.bat --run-now        # 启动先跑一次再等
.\定时任务启动.bat --time 03:20     # 临时改每天 03:20
.\定时任务启动.bat --every 6        # 每 6 小时一次
.\定时任务启动.bat --save-excel     # 定时跑也留 Excel（默认不留）
```

直接调 Python（调试用）：

```powershell
python app\crawler.py                # 导出：本地 Excel + 飞书
python app\crawler.py --no-excel     # 只更新飞书，不存 Excel（定时任务就是这个）
python app\crawler.py --no-feishu    # 只出本地 Excel
python app\crawler.py --date 2026-11-20   # 指定文件名日期
python app\crawler.py --feishu-check # 只验飞书配置
python app\scheduler.py --status     # 看下次运行时间，不跑
python app\scheduler.py --once       # 调度器只跑一次就退出
```

## 3. 定时：调度器 或 计划任务（二选一）

**方式 A：常驻调度器**（推荐，免管理员）

双击 `定时任务启动.bat`。它会用 `pythonw/python app\scheduler.py` 起一个独立进程，主窗口留最小化在任务栏：

- 每次到点用子进程跑 `crawler.py`，跑完子进程退出、内存释放，调度器继续等下一次；
- 关机/注销后需重新双击；想开机自启，把 `定时任务启动.bat` 的快捷方式丢进 `shell:startup`；
- 日志：`output\logs\scheduler_YYYYMMDD.log`（含每次导出的子进程输出尾部）；
- 重复启动会被单实例锁拒绝（退出码 2），不会跑双份。

计划写在 `config\config.json`：

```json
"schedule": { "enabled": true, "mode": "daily", "time": "02:00", "interval_hours": 24, "run_on_start": false }
```

`mode` 改 `interval` 时按 `interval_hours` 间隔跑；`run_on_start: true` 表示每次启动先跑一遍；`save_excel: false` 表示定时跑不落 Excel（默认 false，只更新飞书；改 true 或加 `--save-excel` 才留档）。

**方式 B：Windows 计划任务**（服务器用，无需窗口）

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install_task.ps1            # 默认每天 00:10
powershell -ExecutionPolicy Bypass -File .\scripts\install_task.ps1 -Time "02:30"
schtasks /Run /TN "青鸾项目每日导出"                                            # 立即试跑一次
powershell -ExecutionPolicy Bypass -File .\scripts\uninstall_task.ps1          # 删除任务
```

电脑需处于开机/唤醒状态；笔记本可在「任务计划程序」里勾选「唤醒计算机运行此任务」。

⚠ 方式 A 和 B 不要同时启用，同一时刻会导出两遍。

## 3.5 地图页（手机看项目）

没有服务器，所以做法是「飞书表 → 写进 HTML → 单文件打开」：

- 双击 `备案项目地图.html` 就能看，数据内置在文件里，断网也能用（底图需联网）；
- 数据来自飞书在线表格，右上角「飞书原表 ↗」直达表格；
- 刷新：`python app\build_map_html.py`（3 秒），`定时任务启动.bat` 每次导出成功后会自动刷新；
- 手机：把 `备案项目地图.html` 发到手机，用系统浏览器打开（微信内置浏览器可能拦本地 HTML）。

想局域网实时看，把 `config\config.json` 里 `map.enabled` 改 `true`，调度器会额外在 8787 端口开只读服务，手机同 Wi-Fi 打开 `http://电脑IP:8787/`。细节见 `docs/地图与手机访问.md`。

## 4. 条数口径

页面顶部每个页签各自统计，**「共 N 条」是当前页签的条数**，不是账号全部项目。本账号实际分布：

| 分类 | 条数 |
| --- | --- |
| 备案项目 | 18 |
| 成交项目 | 10 |
| 非备案人报价项目 | 1 |
| 丢失项目 | 2 |
| 失效项目 | 2 |

脚本默认只导「备案项目」18 条（`crawl.tab_types=[100]` 拉全量，再用 `crawl.status_filter=["备案项目"]` 过滤）。要导别的分类，改 `status_filter`（如 `["备案项目","成交项目"]`）。

## 5. 导出结果

- 第一张表：**18 行 × 158 列**，列名与列序取自站点「导出配置」接口，与网页点「导出」的表头 158/158 一致（含两处重复表头「项目进度」、末尾 50 组「签到时间/签到记录」）。
- 第二张表「导出说明」：导出时间、账号、项目数、字段数、来源。
- 同目录 `raw\projects_日期.json` 保存接口原始数据（含 `_follows` / `_signins`）。
- 18 条约 20 秒；带飞书同步约 25 秒。

## 6. 数据来源与几个反直觉的列

| 内容 | 来源接口 |
| --- | --- |
| 项目基础字段 | `POST /api/project/conditionsPage` |
| 项目详情补充 | `GET /api/project-info/select/one/by/{projectId}` |
| 签到时间/记录（50 组） | `GET /api/project-follow/{projectId}`，**只取 `checkInType==1`** |
| 客户/公司性质/资质/挂靠/职位/地址 | `GET /api/project/select/project/contact/by/{projectId}` |
| 挂靠判定 | 联系人档案里的公司 ≠ 项目上填的公司 → 「是」 |
| 列名与列序 | `GET /api/project-info/export/record/100`（59 字段，签到展开 100 列） |
| 登录 | `POST /api/oauth/token`（password 模式，client_id=web） |

- **「未跟进天数」**实际是**最近一次签到时间**（带时分秒），取列表接口的 `checkInTime`。
- **「项目签到次数」**是 `1.0` / `29.0` 这种一位小数。
- 「预计合同金额」「折扣信息」由数组拼成 `报警:3845;` 文本。

## 7. 已知差异

`报价专用2` 这一行的「预计合同金额 / 折扣信息」与网页导出不同：列表接口给 `消防电源监控:252;漏电:488;`（合同额 740），网页导出是 `报警:102198.27;…智能疏散:82594.77;`（约 21 万）。项目报价明细接口 `getProjectAndRequestQuotaitonInfo` 返回 500，暂保留列表口径，其余 17 行 158 列一致。

## 8. 参数（config/config.json）

| 字段 | 含义 |
| --- | --- |
| `crawl.tab_types` | 要扫的标签，`[100]` 是「全部项目」 |
| `crawl.status_filter` | 导哪些分类，默认 `["备案项目"]`；留空导全部 |
| `crawl.page_size` | 每页条数，报 `420 数据过大` 调到 20 |
| `crawl.request_interval` | 请求间隔（秒），默认 0.15 |
| `crawl.with_detail` / `with_follow` / `with_client` | 是否取详情 / 签到 / 联系人 |
| `export.checkin_columns` | 签到列组数，默认 50（对齐网页导出，别改） |
| `export.keep_days` | 历史 Excel 保留天数 |
| `export.output_dir` | 输出目录，相对路径按工程根目录解析 |
| `feishu.enabled` | 是否每次覆盖更新飞书在线表格 |
| `schedule.time` | 调度器每天几点跑，默认 `02:00` |
| `schedule.mode` / `interval_hours` | `interval` 时按小时间隔跑 |
| `schedule.run_on_start` | 调度器启动是否先跑一次 |
| `schedule.save_excel` | 定时跑是否保存本地 Excel，默认 `false`（只写飞书） |
| `map.enabled` | 是否额外开局域网地图服务，默认 `false` |
| `map.port` | 地图服务端口，默认 `8787` |
| `map.snapshot` | 导出后是否自动把飞书表写回地图 HTML，默认 `true` |

## 9. 常见报错

| 现象 | 处理 |
| --- | --- |
| `code=001 用户或密码错误` | 账号密码不对；检查 `config/credentials.json` 或环境变量 |
| `401 / 010 登录已失效` | token 过期，清空 `login.token`，走账号密码 |
| `420 数据过大` | 调小 `page_size` |
| `ModuleNotFoundError: requests` | 装依赖：`python -m pip install -r app\requirements.txt` |
| `Unexpected UTF-8 BOM` | 已兼容（按 `utf-8-sig` 读） |
| 导出表是空的 | `status_filter` 与账号分类不符；先 `--verify` |
| 计划任务没产物 | 看 `output\logs\crawl_日期.log` 与 `run_error.log`；多为关机或 Python 不在 PATH |
| 调度器退出码 2 | 已有调度器在跑（51877 端口被占）；关掉旧的最小化窗口再启 |
| 定时跑了两遍 | 常驻调度器和 Windows 计划任务同时启用了，关掉一个 |
| 手机打不开地图 | 服务没起 / 不在同一网络 / 防火墙拦 8787；见 `docs/地图与手机访问.md` |

## 10. 说明

- 脚本只读接口，不提交、不修改业务数据；能导出什么取决于账号权限。
- 客户名称、联系人、电话、金额属公司业务数据，按公司规定存放。
