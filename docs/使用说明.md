# 使用说明

版本：V3.0　最后更新：2026-11-22　适用：Windows，日常使用者

## 一、它是什么

一个 HTML 页面、一个云端 JSON、一张地图。页面只从同目录 `./data.json` 读数据；数据由 GitHub Actions 每天抓取、校验、脱敏后写入。电脑关机也照常更新。

- 在线地图（脱敏公开）：<https://reckt5138-lab.github.io/beian-map/>
- 完整 158 列原始数据：只在本机 `output/` 和 Actions 临时目录，不公开

## 二、唯一入口：双击「青鸾地图.bat」

| 编号 | 功能 |
|---|---|
| 1 | 首次配置 / 部署 |
| 2 | 一键更新代码并部署 |
| 3 | 手动刷新云端数据 |
| 4 | 本地抓取（只写完整 JSON 到 `output/`） |
| 5 | 本地预览地图（起 127.0.0.1 服务） |
| 6 | 项目诊断 |
| 0 | 退出 |

安装只需 Python 3.12+ 与 Git，然后 `python -m pip install -r requirements.txt`。

## 三、日常怎么看数据

- 手机/电脑：直接开 <https://reckt5138-lab.github.io/beian-map/>。
- 本地：菜单 5。页面请求同目录 `./data.json`，必须用 HTTP 服务打开；双击 `index.html`（file://）读不到数据。

## 四、本地抓一次数据

1. 菜单 4，或 `python -m app.main crawl` → 产出 `output/data.full.json`（完整矩阵，只在本机）。
2. `python -m app.main publish --source output\data.full.json` → 写 `data.json`（13 列白名单）、`index.html`、`dist/`。
3. 菜单 5 预览。

## 五、页面状态说明

| 显示 | 含义 |
|---|---|
| 正在读取云端数据… | 正在请求 `./data.json`，此时不显示条数 |
| 云端数据 HH:MM · N 条 | 加载成功，N 是真实项目数 |
| 云端数据加载失败，请稍后刷新页面。 | 读取失败，列表清空，不会伪造 0 条 |

## 六、常见问题

- **显示加载失败**：`./data.json` 拿不到——文件不在同目录、服务没起、或云端发布失败。先刷新，再确认 `data.json` 存在。
- **改了账号密码**：改仓库 Secrets（`JUFA_USERNAME` / `JUFA_PASSWORD`），本机同步改 `config/credentials.json`。
- **想加公开字段**：见 `docs/开发维护.md`「加字段」一节；不要放客户、金额、联系人一类字段。
- **本地抓取失败**：菜单 6 看诊断报告（`output/logs/diagnostic_report.txt`）。
