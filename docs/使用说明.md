# 使用说明

版本：V2.1 Lite 　最后更新：2026-11-21 　适用：Windows，日常使用者

## 一、它是什么

每天在云端（GitHub Actions，免费）自动登录青鸾、抓取备案项目、校验、脱敏，生成一张在线地图。电脑关机也照常更新。

- 在线地图（脱敏）：<https://reckt5138-lab.github.io/beian-map/>
- 本地完整数据（158 列 + Excel）：只在这台电脑上

## 二、唯一入口：双击「青鸾地图.bat」

打开后是一个菜单，选编号回车即可：

| 编号 | 功能 | 什么时候用 |
|---|---|---|
| 1 | 首次配置 / 部署 | 第一次用，或换新电脑 |
| 2 | 一键更新代码并部署 | 改了代码要上线 |
| 3 | 手动刷新云端数据 | 想立刻更新一次数据 |
| 4 | 本地抓取并导出 Excel | 要 158 列完整表格 |
| 5 | 打开本地地图 | 在本机浏览器看 |
| 6 | 项目诊断 | 出问题了先跑这个 |
| 0 | 退出 | — |

不需要懂 Python、Git 或命令行；失败时菜单会打印退出码，并把原因写进 `output/logs/`。

## 三、安装（只需一次）

1. 安装 Python 3.12 / 3.13（勾选 `Add python.exe to PATH`）
2. 安装 Git（[git-scm.com](https://git-scm.com)）
3. 双击「青鸾地图.bat」→ 选 **1 首次配置 / 部署**
4. 按提示输入青鸾账号（保存在 `config/credentials.json`，不进 Git）
5. 脚本会建虚拟环境、装依赖、验证登录、试抓一次
6. 按提示到 GitHub 网页配置 Secrets（见 `部署说明.md` 第三节）

## 四、首次配置要点

- 账号：`config/credentials.json`（本机唯一保存真实账号的位置）
- 云端账号：GitHub → Settings → Secrets → `JUFA_USERNAME` / `JUFA_PASSWORD`
- 提交令牌：`PUSH_TOKEN`（fine-grained，仅本仓 `Contents: Read and write`）
- 仓库与分支：`config/config.json` → `publish`

## 五、打开地图

**菜单 5**：启动只监听 `127.0.0.1` 的本地服务（默认 8787，占用时自动换端口），并打开浏览器。关闭：窗口 `Ctrl+C`，或直接关窗口。

页面功能：标记、搜索、按失效时间筛选、项目详情、坐标可信度（`geo`）、高德导航、手机端单列布局。

## 六、刷新数据

**菜单 3**：触发云端 `daily.yml`，只刷数据不改代码。需要本机 `gh` 已登录（`gh auth login`）。

云端每天北京时间 02:10 也会自动跑一次。

## 七、导出 Excel

**菜单 4**：真抓一次，产出：

| 文件 | 说明 |
|---|---|
| `output/excel/备案项目YYYY-MM-DD.xlsx` | 由 `crawl` 生成后自动打开（若路径在 output 根目录同样可用） |
| `output/data.full.json` | 158 列完整 payload |
| `output/raw/projects_YYYY-MM-DD.json` | 接口原始数据 |

同步刷新本地地图，**不会推送**，不影响线上。

## 八、日常操作

| 想做什么 | 怎么做 |
|---|---|
| 看线上数据是不是最新 | 打开在线地图，顶部有数据时间 |
| 桌面看全量 | 菜单 4 + 菜单 5 |
| 改配置 | `config/config.json`，改完菜单 2 |
| 备份 | 复制整个 `output/` 到移动硬盘（不要提交 Git） |
| 恢复某天 | 把 `output/raw/projects_那天.json` → `output/data.full.json`，再跑 `python -m app.main build-json` + `build-map` |

## 九、常见问题

| 现象 | 处理 |
|---|---|
| 菜单一闪就关 | 双击后若报错，窗口会 pause；也可在 PowerShell 里运行 `scripts\menu.py` 看详细报错 |
| `python` 不是内部命令 | 重装 Python 并勾选 PATH，重开窗口 |
| 登录失败 | 检查 `config/credentials.json` 的 `username` / `password`；或网页登录确认账号状态 |
| 抓取 0 条 | 青鸾可能改版，先看 `output/logs/` 与 `output/raw/` |
| 地图打不开 | 端口被占会自动换端口，按窗口打印的地址打开 |
| 推送失败 | 用菜单 2（内部走 GitHub API，不依赖 `git push`） |
| 线上没更新 | 打开 Actions 看最近运行；红灯看第一个失败步骤 |

更细的排查见 `部署说明.md` 第七节；数据结构与脱敏规则见 `数据与安全.md`。
