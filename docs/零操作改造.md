# 零操作改造说明（v2 · 无飞书版）

本目录 `jbufa_project_export_v2` 是独立的副本项目，原工程 `jbufa_project_export` 保持原样，未做任何修改。

## 一句话逻辑

**云端定时抓数 → 直接出 `data.json` + Excel → 免费静态网页随时看。不经过飞书、不需要电脑开机、不需要服务器。**

## 三个角色分工

| 角色 | 在哪 | 命令/入口 | 产出 |
| --- | --- | --- | --- |
| 测试 | 本地电脑 | `测试运行.bat` | `output\备案项目YYYY-MM-DD.xlsx`（自动用 Excel 打开）+ `data.json` + 本地 `index.html` |
| 定时 | 云端 GitHub Actions | `.github\workflows\daily.yml` | `data.json`（提交回仓库）+ Pages 发布 + xlsx Artifact |
| 看数 | 任意设备 | `https://项目名.pages.dev/` 或本地 `打开地图.bat` | 只读地图 + 全部 158 列字段 |

## 改了什么

| 文件 | 变化 |
| --- | --- |
| `app/map_payload.py`（新） | 二维表 → `data.json`，幂等写（内容没变不落盘），只依赖 `sheet_to_projects` 的解析函数，避免与 crawler 循环引用 |
| `app/crawler.py` | 新增 `--json-out`：抓完在内存矩阵上直接生成 `data.json`，**跳过飞书这一步**；矩阵复用，不多跑一遍 |
| `app/build_data_json.py`（重写） | 三种数据源：`--raw`（原始 JSON，默认取最新）、`--from-xlsx`（Excel 反推）、`--from-json`（规范化已有 data.json）；另有 `--out`、`--dry-run` |
| `.github/workflows/daily.yml`（重写） | `crawler.py --no-feishu --json-out data.json` → `build_map_html.py --from-json` → 校验 → 只提交 `data.json` → Pages 发布 → 上传 xlsx Artifact；没有任何飞书步骤与飞书 Secret |
| `测试运行.bat`（重写） | 本地三连：抓数 → 出 data.json → 重建 index.html，并自动打开最新 Excel |
| `scripts/deploy_github.py`、`一键部署.bat`（新） | 一键建仓/推送/写 Secrets（`JUFA_USERNAME`、`JUFA_PASSWORD`，本机 pynacl 加密）/回填 publish/触发 Actions；加 `--cf-*` 可顺带配 Cloudflare Pages（免费） |
| `app/build_map_html.py` | 支持 `--from-json`（不连飞书也能构建），构建时把云端仓库地址注入页面 `window.CLOUD` |
| `app/map_template.html` | 数据源多级回退 + 单源 5 秒超时，Raw 与 jsDelivr 并行竞速 |
| `README.md`、`docs/部署清单.md`、本文件 | 全部改为「无飞书」口径 |

旧飞书路线（`app/sheet_to_projects.py`、`app/scheduler.py`、`定时任务启动.bat`、`cloud/feishu_proxy_worker.js`、`docs/飞书*.md`、`docs/云端自动运行.md`）保留但不再被调用，删掉不影响新版。

## 数据源回退顺序（页面）

1. `?data=` 手动指定
2. Cloudflare Pages 同源 `./data.json`（部署到 Pages 时就是当天数据，最快）
3. GitHub Raw 与 jsDelivr 并行竞速（5 秒超时）
4. `?repo=owner/repo` 临时指定仓库
5. 内置快照 `window.EMBEDDED`
6. `localStorage` 上次成功数据

## 已验证

- `crawler.py --no-feishu --json-out` 的数据路径与 `build_data_json.py --from-xlsx` 等价：18 条 / 158 列 / 每项目 35 个字段。
- 幂等：第二次生成打印「无变化，跳过写入」。
- `build_map_html.py --from-json data.json` 生成的 `index.html` / `备案项目地图.html` 各 18 条，本地 HTTP 实测渲染正常（状态栏「本地数据 · 18 条」）。
- `deploy_github.py --dry-run` 通过：约 47 个文件、Secrets 仅 `JUFA_USERNAME` / `JUFA_PASSWORD`（带 `--cf-*` 时才追加 `CLOUDFLARE_*`）。
- 五个 py 文件 `ast.parse` 全通过。

## 已知限制

- `file://` 双击打开无法 fetch，本地看最新要经 `打开地图.bat` 起 HTTP。
- Private 仓库读不到 Raw/jsDelivr，本地页面只能看内置快照 —— 实时访问请用 Pages 链接；建议仓库设为 Public。
- 云端抓数依赖青鸾账号；账号密码只放仓库 Secrets，`config/credentials.json` 已被 `.gitignore` 挡住。
- Actions 的 `schedule` 有几分钟排队延迟（正常现象，不影响当天数据）。
