# 开发维护

版本：V2.1 Lite 　最后更新：2026-11-21 　面向：接手的开发者 / Agent

## 一、架构

```
青鸾地图.bat → scripts/menu.py（只做菜单）
                 ├ scripts/first_setup.py  首次部署
                 ├ scripts/deploy_update.py 更新部署（API 推送）
                 ├ scripts/refresh.py       触发云端
                 ├ scripts/local_server.py  本地地图
                 └ scripts/maintenance.py   诊断
app/main.py（7 命令 CLI）
   ├ app/core      paths / config / logging_config / exceptions
   ├ app/data      atomic / validate / export_json
   ├ app/map       build（渲染 + verify）
   ├ app/security  sanitize（白名单脱敏）
   ├ app/crawler.py        采集核心（68KB，原地保留）
   ├ app/map_payload.py    矩阵 → payload，原子写 + 幂等
   └ app/build_map_html.py 渲染（被 app/map/build 调用）
```

依赖方向单向：`main/map/data/security → core`，`core` 不依赖业务模块，无循环。

## 二、目录职责

| 路径 | 职责 | 是否进 Git |
|---|---|---|
| `app/crawler.py` | 登录、分页、详情、158 列矩阵、Excel | 是 |
| `app/map_payload.py` | payload 构建/保存/坐标合并 | 是 |
| `app/build_map_html.py` | 用模板渲染页面 | 是 |
| `app/map_template.html` | 页面模板（Leaflet、搜索、筛选、详情） | 是 |
| `app/publish_commit.py` | 走 Contents API 提交 data.json / index.html | 是 |
| `app/main.py` | 统一命令入口 | 是 |
| `config/config.json` | 业务配置（**不含任何密钥**） | 是 |
| `config/credentials.json` | 真实账号 | **否** |
| `output/` | raw / excel / logs / 临时 | **否** |
| `data.json` / `index.html` | 脱敏发布产物 | 是 |
| `dist/` | 部署临时目录 | **否** |

## 三、数据流程

```
crawler（登录 → 列表分页 → 详情 → 矩阵）
   → output/data.full.json（158 列）
   → validate（总数/分页/重名/日期/坐标/异常下降）
   → sanitize（白名单 → 13 列公开）
   → build_map（index.html + 内置快照）
   → verify（大小/凭证/快照）
   → dist/ → Contents API 提交 → Pages（CF 可选）
```

## 四、改代码前必跑

```bat
python -m compileall -q app scripts tests
python -m unittest discover -s tests -q
python -m app.main selftest
```

## 五、常见扩展

**加采集字段**
1. `app/crawler.py` 表头映射加列（签到列在 36–157，注意顺序）
2. `app/data/export_json.py` 的 `matrix_to_payload` 映射到 `projects[i]`
3. 要公开 → `config/public_fields.example.json` 的 `projects_keep` / `columns_keep`
4. 加测试 + 更新 `docs/数据与安全.md`

**加筛选条件**
1. `app/map_template.html` 加控件（参考失效时间筛选块）
2. 页面 `filterProjects()` 加判定；同一份数据同时供列表与地图

**加统计**
在前端算（数据量小），或在 `app/map/build.py` 生成时附加 `stats`；不要往工作流加步骤。

**换底图**：`app/map_template.html` 的 `L.tileLayer(...)`。

**接新数据源**：新建 `app/crawler/<source>.py`，输出与 `data.full.json` 同结构（`columns/rows/projects`），在 `app/main.py` 加子命令，改完立刻 `validate`。

## 六、铁律

- 不改青鸾登录方式/接口路径/分页/字段映射（`config/config.json` 的 `api`、`crawl`）
- 不把 `crawler.py`、`map_payload.py` 拆散重写（158 列强耦合）
- 新增公开字段必须走白名单 + `sanitize`，不能直接塞进 `data.json`
- 发布只用 `app/publish_commit.py`（API），不引入 `git push` 主路径
- 不引入数据库、收费服务、新框架
