# 开发维护

版本：V3.0　最后更新：2026-11-22　面向：接手的开发者 / Agent

## 一、架构

```
青鸾地图.bat → scripts/menu.py（只做菜单）
                 ├ scripts/first_setup.py    首次部署
                 ├ scripts/deploy_github.py  建库 / 推代码 / 写 Secrets / 触发 Actions
                 ├ scripts/deploy_update.py  更新部署（API 推送）
                 ├ scripts/refresh.py        触发云端
                 ├ scripts/local_server.py   本地起 HTTP 服务看地图
                 └ scripts/maintenance.py    诊断
app/main.py（7 命令 CLI）
   ├ app/core      paths / config / logging / exceptions
   ├ app/crawler.py       登录、分页、详情 → 完整矩阵 JSON
   ├ app/matrix_parse.py  矩阵解析 + 区域坐标补全
   ├ app/map_payload.py   矩阵 → payload、原子写、幂等
   ├ app/data      validate / atomic / export_json（脱敏写 data.json）
   ├ app/security  sanitize（13 列白名单）
   ├ app/map       build（模板拷贝 + verify）、dist
   └ app/build_map_html.py  把 map_template.html 拷成 index.html
```

依赖单向：`main / map / data / security → core`，`core` 不依赖业务模块。

## 二、目录职责

| 路径 | 职责 | 是否进 Git |
|---|---|---|
| `app/crawler.py` | 登录、分页、详情、完整矩阵（158 列） | 是 |
| `app/matrix_parse.py` | 表头映射、日期归一、坐标补全 | 是 |
| `app/map_payload.py` | payload 构建、原子写、幂等 | 是 |
| `app/map_template.html` | 唯一页面模板（单源 `./data.json`） | 是 |
| `app/build_map_html.py` | 模板 → index.html（不内嵌数据） | 是 |
| `app/map/build.py` | build / verify / copy_to_dist | 是 |
| `config/config.json` | 运行配置（无凭证） | 是 |
| `config/credentials.json` | 青鸾账号密码 | 否 |
| `config/deploy.json` | 部署 token（可选） | 否 |
| `data/coords.json` | 区域坐标表 | 是 |
| `output/` | 完整 JSON、日志 | 否 |
| `index.html` / `data.json` / `dist/` | 生成产物 | 视发布方式 |

## 三、数据流

```
青鸾网页
  → crawler.py（登录、分页、详情） → output/data.full.json（158 列，只在本机/runner）
  → map_payload（矩阵 → payload）
  → security.sanitize（13 列白名单，敏感字段置空）
  → data.validate（空集/骤降/重复/日期/分页完整性）
  → data.export_json → data.json
  → map.build → index.html（只请求 ./data.json）
  → dist/（只含 index.html + data.json）→ Pages
```

失败保护：抓取失败或校验不通过时 `publish` 不写新 `data.json`；Actions 步骤失败则不会提交，上一版有效数据继续在线。

## 四、命令

```bat
python -m app.main crawl                                  :: 抓取 → output/data.full.json
python -m app.main build-json --source output/data.full.json
python -m app.main build-map
python -m app.main publish --source output/data.full.json  :: 脱敏→校验→构建→dist
python -m app.main validate --source data.json
python -m app.main selftest
python -m app.main diagnose
python -m unittest discover -s tests -v
```

## 五、加字段

1. `app/security/sanitize.py` 的白名单（`config/public_fields.example.json`）加字段名；
2. `app/map_template.html` 里 `checkPayload` / 渲染函数读取该字段（字段不存在时给默认值，别报错）；
3. `tests/test_security.py` 补一条断言，`tests/test_map.py` 的「不内嵌数据」断言仍须通过；
4. `python -m unittest discover -s tests -v` 全绿再发布。

禁止：把客户名、业务员、金额、联系人、客户地址、签到明细放进公开白名单。

## 六、页面约定

- 唯一业务数据请求：`const DATA_URL = './data.json'`；不得出现 raw.githubusercontent、jsDelivr 数据接口、飞书接口、内置快照、localStorage 缓存。
- 加载中显示「正在读取云端数据…」，`fabN` 显示 `—`，绝不显示 0；失败显示「云端数据加载失败，请稍后刷新页面。」并清空统计、列表、标记。
- `verify()` 会拦截：凭证前缀（`ghp_` / `cli_`）、明文密码、旧数据源地址、`window.EMBEDDED`；页面小于 20 KB 也判失败。
