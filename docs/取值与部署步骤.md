# 取值 + 部署：照着点就行（全免费）

一共 5 步，前 3 步在浏览器里复制几个值，第 4 步在本机敲一条命令，第 5 步验证。

---

## 第 0 步：本机环境（只需做一次）

打开 PowerShell（Win 键 → 输入 `powershell` → 回车），粘这两行：

```powershell
cd 'C:\Users\Administrator\Desktop\新建文件夹 (3)\jbufa_project_export_v2'
python -m pip install -r app\requirements.txt pynacl
```

看到 `Successfully installed ...` 就行。`python` 若提示找不到命令，把 python.exe 的完整路径写进项目根目录的 `python_path.txt`（一行，纯路径，无引号）。

---

## 第 1 步：GitHub 用户名 + 仓库名（1 分钟）

1. 打开 <https://github.com> 登录（没有账号就 Sign up，免费）。
2. 右上角头像 → **Your profile**，地址栏 `github.com/` 后面那串就是**用户名**。
   例：`https://github.com/tommy2021` → 用户名 `tommy2021`。
3. **仓库名**自己起，只能用字母、数字、`-`、`_`，建议 `beian-map`。
   不用提前创建，部署脚本发现没有会自动建。

---

## 第 2 步：GitHub Token（3 分钟，唯一有点绕的一步）

1. 打开 <https://github.com/settings/tokens>
2. 点 **Tokens (classic)** → 右上 **Generate new token (classic)**（如果弹提示要你选 classic / fine-grained，选 **classic**）。
3. 填：
   - **Note**：`beian-deploy`
   - **Expiration**：`90 days`（到期重新生成一个就行）
   - **Select scopes** 勾两个：
     - ☑ **`repo`**（勾最上面那个 `repo` 就整块全勾上，够用）
     - ☑ **`workflow`**（推 `.github/workflows` 必须要，不勾会 403）
     - 其余一个都不用勾
4. 最下面 **Generate token** → 页面出现 `ghp_xxxxxxxx...`
5. 点旁边的复制图标，**先粘到记事本存好**——离开页面就再也看不到这串了（丢了只能重新生成）。

> 安全说明：Token 只在这一次部署时用（建仓库、写 Secrets、触发 Actions），脚本不会留在 `.git/config`，也不会写进任何提交的文件。

---

## 第 3 步（可选）：Cloudflare 三项 —— 只是"国内访问更稳"，不是必需

默认已经用 **GitHub Pages** 发布，部署完就有 `https://你的用户名.github.io/仓库名/`，零额外账号。
想做国内更稳的加速，再配 Cloudflare Pages：

**a. 注册**：<https://dash.cloudflare.com/sign-up>（免费，不用绑卡、不用加域名）。

**b. 拿 Account ID**：
登录后看控制台右侧栏，或进 **Workers & Pages** 概览页，右侧 **Account ID** 那一串 32 位字符，复制。

**c. 拿 API Token**：
1. 右上头像 → **My Profile** → 左侧 **API Tokens** → **Create Token**
2. 拉到最下面 **Create Custom Token** → **Get started**
3. 填：
   - Token name：`pages-deploy`
   - **Permissions**：第一行选 `Account` → `Cloudflare Pages` → 级别 `Edit`
   - Account Resources：`Include` → 你的账号
   - Zone Resources / Client IP / TTL：全部留空默认
4. **Continue to summary** → **Create Token** → 复制那串 token（同样只显示一次）

**d. 项目名**：就用 `beian-map`。不用手动建项目——第一次部署时 wrangler 会自动创建同名 Pages 项目。

---

## 第 4 步：一键部署（一条命令）

回到刚才那个 PowerShell 窗口（在项目目录里），把四个值换成你的：

```powershell
python scripts\deploy_github.py --owner 你的用户名 --repo beian-map --token ghp_xxx
```

想同时配好免费网页，加上三个 CF 参数（不配就删掉这行尾）：

```powershell
python scripts\deploy_github.py --owner 你的用户名 --repo beian-map --token ghp_xxx `
  --cf-token CF的Token --cf-account CF的AccountID --cf-project beian-map
```

或者不要命令行，**双击 `一键部署.bat`**，它会依次问你要用户名、仓库名、Token（Token 输入时不回显），CF 三项走参数或后面再补。

脚本会依次打印：

```
✓ Token 有效，登录身份：xxx
✓ 仓库已创建：https://github.com/xxx/beian-map
· 推送 47 个文件...
✓ Secrets 已写入：JUFA_USERNAME / JUFA_PASSWORD
✓ index.html 已重建（含云端地址）
✓ Actions 已触发
 网页：https://beian-map.pages.dev/
```

中途报错先别关窗口，照最后一行的提示处理（对照文末"卡点"）。

---

## 第 5 步：验证（3 分钟）

1. 打开 `https://github.com/你的用户名/beian-map/actions`，能看到一条正在跑的任务「备案项目每日更新」。
   跑完（1–3 分钟）点进去，日志里应有 `抓取完成`、`data.json OK：18 条 / 158 列`。
2. 仓库首页刷新，根目录出现 `data.json`，提交时间就是刚才。
3. 该次运行的页面底部 **Artifacts** 里能下载 `备案项目-xxxx.zip`，解压是当天 Excel（保留 30 天）。
4. 手机或电脑打开 `https://你的用户名.github.io/仓库名/`（GitHub Pages，已自动发布），
   状态栏显示今天日期 + 18 条，就是通了。配了 Cloudflare 的话 `https://项目名.pages.dev/` 也能开。
5. 本地验数据：双击 `测试运行.bat`，跑完自动打开当天 Excel。

以后每天北京时间 **02:10** 自动跑一次，你什么都不用做；想看就打开 Pages 链接。

## 卡点速查

| 现象 | 处理 |
| --- | --- |
| `Token 无效` / 401 | Token 复制不完整（漏字符或带空格），重新复制 |
| 推送报 403、`refusing to allow a Personal Access Token` | Token 没勾 `workflow`，重新生成 |
| Actions 报 `Permission denied` | 仓库 Settings → Actions → General → Workflow permissions 选 **Read and write permissions**（脚本一般已自动设，私有仓库偶发） |
| Actions 日志 `code=001` / 登录失败 | Secrets 里账号密码不对：仓库 Settings → Secrets and variables → Actions 里改 `JUFA_USERNAME` / `JUFA_PASSWORD` |
| Pages 步骤失败 | CF 三项缺一个；或 Token 权限不是 `Account → Cloudflare Pages → Edit` |
| 网页一直显示内置快照 | 仓库是 Private（本地直读不到 Raw）→ 用 Pages 链接；或改回 Public |
| 手机打不开 Pages 链接 | 部署后第一次生效要 30–60 秒，稍等刷新 |

## 之后想改的东西

| 想改 | 怎么改 |
| --- | --- |
| 每天跑的时间 | `.github\workflows\daily.yml` 里 `cron: "10 18 * * *"`（UTC，18:10 = 北京 02:10），改完推送 |
| 页面样式 | `app\map_template.html`，改完本地跑 `python app\build_map_html.py --from-json data.json --out index.html` 看效果 |
| 账号密码 | GitHub 仓库 Secrets 里直接改，不用动代码 |
| 重新部署一遍 | 再跑一次第 4 步命令，脚本幂等：已有仓库不重建、Secrets 覆盖、页面重建、Actions 再触发 |
