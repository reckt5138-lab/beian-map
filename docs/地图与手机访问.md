# 地图页：电脑和手机都能看，零成本

## 两种看法

| 方式 | 场景 | 数据 |
| --- | --- | --- |
| **局域网实时**：手机/电脑浏览器打开 `http://192.168.1.28:8787/` | 电脑开着、手机连同一 Wi-Fi | 每次打开都读飞书表（缓存 90 秒） |
| **离线快照**：把 `备案项目地图.html` 发到手机，用系统浏览器打开 | 出门、断网、电脑关机 | 文件里打包的那份（时间戳写在标题下） |

两种都在用，不冲突：网页先试局域网接口，取不到再退回内置快照。

## 只读 + 全字段（这一版新增）

- **只读**：页面只有展示，没有任何编辑/上传/写入入口，也没有写接口；标题旁有灰色「只读」标记。数据是导出时写进文件的，看的人只能看。
- **全字段**：点任意圆点（手机点底部项目卡）打开详情，滑到底有「全部字段 · 只读」，默认折叠，显示「展开 XX 项（飞书表 158 列，只显示非空值）」。点开就是飞书原表的逐行字段：项目名称、地址、业务员、审批类型、客户信息、报价、进度、签到次数、公司资质、挂靠、职位……158 列里所有非空的都带上（签到时间/签到记录已整理成上面的时间轴，不重复列）。
- **深链**：`备案项目地图.html?open=0` 直接打开第 1 条详情（数字从 0 开始），方便发某一条给别人看。

全字段对文件体积影响：18 条时 HTML 约 95 KB（自带快照），`projects.json` 约 53 KB，手机打开无压力。

## 谁在跑

`定时任务启动.bat` → `app\scheduler.py`，一个进程同时干三件事：

1. 每天 02:00（可改）登录青鸾抓 18 条 → 覆盖更新飞书表；
2. 导出成功后把飞书表内容写回 `备案项目地图.html`（内置快照）；
3. 在 8787 端口开只读页面服务（`/` 发页面，`/projects.json` 读飞书）。

已注册开机自启（登录后自动最小化运行），不用每天手动点：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install_autostart.ps1              # 安装
powershell -ExecutionPolicy Bypass -File .\scripts\install_autostart.ps1 -Uninstall   # 取消
```

## 手机第一次能打开的前提

1. **同一 Wi-Fi**：手机和电脑在同一路由器下（别用访客网络，访客网络会隔离设备）。
2. **电脑不睡**：睡眠/休眠会断服务；电源选项里把睡眠设为「从不」，或插电时禁用睡眠。
3. **放行防火墙**：第一次手机打不开多半是 Windows 防火墙。管理员运行 `scripts\open_firewall.bat`（放行 TCP 8787）。
4. **IP 别变**：`192.168.1.28` 是这台电脑当前内网地址，重启可能变。推荐在路由器里给它做「静态地址分配 / MAC 绑定」；或 Windows 设静态 IP。IP 变了怎么查：`定时任务启动.bat` 窗口会打印「手机：http://…:8787/」，或 `ipconfig`。

## 想 4G 下随时看

那需要公网地址，三条路线：

- **GitHub Pages / Cloudflare Pages**（免费静态托管）：上传 `备案项目地图.html` + 生成的 `projects.json`，URL 固定、手机随时开。缺点：要账号；仓库公开时客户名会被搜索引擎看到。
- **GitHub Actions 定时跑脚本**（免费，电脑关机也行）：抓取脚本搬到 GitHub 云端每天跑。需要 GitHub 账号；runner 在国外，能否登录青鸾需实测。
- **对象存储（阿里云 OSS / 腾讯云 COS）**：几元/月，国内最快，可私有。

## 刷新内置快照

```powershell
python app\build_map_html.py                                       # 写回 备案项目地图.html
python app\build_map_html.py --out D:\备案项目地图-手机版.html       # 另存一份发手机
```

调度器每次导出成功后会自动跑这条（日志：`已写内置快照 …`）。

## 坐标从哪来

飞书表里没有经纬度，坐标在 `data\coords.json`：现有 18 条精确坐标；新增项目按地址里的区落到区中心并偏移（图例注明近似）；海外/认不出区的标「异地」不画点。要精确就加一行 `"项目名": [纬度, 经度]`（WGS84，页面自动转高德坐标）。

## 为什么网页不能直接连飞书

- `open.feishu.cn` 不返回 `Access-Control-Allow-Origin`，浏览器跨域请求被拦（实测 OPTIONS 404）；
- 调接口要先用 `app_secret` 换 token，写进网页等于把数据钥匙公开。

所以由 8787 的本机服务代读，或导出时把数据写进 HTML。

**注意**：把应用改成「只读权限」也不能让密钥直接进网页——浏览器那一步（跨域）就走不通，飞书官方也要求凭证只在服务端用。要手机 4G 实时看，就用免费 Worker 中转：密钥在云端变量、网页零密钥，见 `docs\飞书实时（免费Worker）.md`。

## 排错

| 现象 | 处理 |
| --- | --- |
| 手机打不开 `http://IP:8787/` | 同一 Wi-Fi？电脑睡了？防火墙？跑 `scripts\open_firewall.bat` |
| 页面显示「内置快照」而不是实时 | 局域网接口没取到：确认调度器在跑、端口对、IP 没变 |
| IP 变了 | 路由器绑定 MAC 或用 `ipconfig` 查新 IP，手机书签改一下 |
| 数据旧 | 看标题下时间戳；点「点此刷新」强制刷新；要最新就跑 `测试运行.bat` |
| 圆点位置偏 | 该项目的地址只到区级，补 `data\coords.json` |
| 手机打 HTML 白屏 | 别用微信内置浏览器，换系统浏览器 / Safari |
