# 电脑关机也能每天更新（云端自动运行）

## 思路

电脑会关机，所以把「每天跑脚本」搬到 GitHub 的免费云端机器（GitHub Actions）：

- 每天 02:10（北京时间）自动跑一次：登录青鸾 → 更新飞书在线表格 → 重新生成 `备案项目地图.html`；
- 生成好的网页自动发布到 Cloudflare Pages，链接固定；
- 手机浏览器打开那个链接就是当天数据，**电脑关机、你出差都没影响**；
- 费用 0：私有仓库的 Actions 每月免费 2000 分钟，这个任务每天约 1 分钟；Cloudflare Pages 免费。

```
GitHub 云端（定时 02:10）
   └─ 跑 app/crawler.py --no-excel        → 覆盖飞书在线表格
   └─ 跑 app/build_data_json.py           → data.json（页面读的就是它）
   └─ 跑 app/build_map_html.py --from-json data.json
                                          → index.html / 备案项目地图.html（内置快照 + 云端地址）
   └─ git add data.json && push           → 数据回写仓库（内容没变就不提交）
   └─ 发布到 Cloudflare Pages              → 手机/电脑打开网址即当天数据
```

本地页面（`index.html`）打开时按这个顺序拿数据，前一个失败自动换下一个：

1. 同目录 `./data.json`（本地 HTTP 服务 / Pages）
2. `https://raw.githubusercontent.com/owner/repo/branch/data.json` —— 无 CDN 缓存，push 后立刻最新
3. `jsDelivr` —— 国内访问更稳，可能有缓存延迟（workflow 里已带 purge 刷新）
4. 内置快照 → localStorage 缓存

所以**你不需要 git pull、不需要同步文件**，Actions 一提交，页面下次打开就是新的。

## 一次性配置（大约 10 分钟）

### 1. 建私有仓库

GitHub → New repository → 名字如 `beian-map` → **Private** → Create。

把工程上传进去（网页版 Upload files 可以整个文件夹拖进去；或 GitHub Desktop）。**不要上传 `config/credentials.json`**（`.gitignore` 已挡住，别用 `git add -f`）。

### 2. 加 Secrets（仓库 Settings → Secrets and variables → Actions）

| 名称 | 值 |
| --- | --- |
| `JUFA_USERNAME` | 青鸾账号 |
| `JUFA_PASSWORD` | 青鸾密码 |
| `FEISHU_APP_SECRET` | 飞书应用 app_secret |
| `CLOUDFLARE_API_TOKEN` | Cloudflare API Token（下一步拿） |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare 账号 ID（右侧栏可见） |
| `CLOUDFLARE_PROJECT_NAME` | 如 `beian-map`（Cloudflare Pages 项目名） |

### 3. Cloudflare Pages

1. 注册 <https://dash.cloudflare.com>（免费）。
2. Workers & Pages → Create → **Pages** → Direct Upload → 项目名填 `beian-map` → 创建（先不用上传文件）。
3. 右上头像 → My Profile → API Tokens → Create Token，权限选 **Cloudflare Pages: Edit**，复制 token。

### 4. 跑第一次

仓库 → Actions → 「备案项目地图每日更新」→ Run workflow → 等 2 分钟。

- 成功：日志里能看到「飞书在线表格已更新」「已写内置快照」，Cloudflare 里出现部署记录；
- 拿到链接：`https://beian-map.pages.dev/`（项目名不同就替换）。

手机打开这个链接，加个书签，以后每天自动是新的。

## 仓库要不要 Public

| | Public 仓库 | Private 仓库 |
| --- | --- | --- |
| 本地 `index.html` 直接读 Raw / jsDelivr | ✅ 可以，零鉴权 | ❌ Raw 对未登录请求返回 404，jsDelivr 也读不到 |
| Cloudflare Pages 链接 | ✅ | ✅（Pages 部署了 `data.json`，链接本身可读） |
| 数据暴露面 | 18 条客户信息公网可读 | 只有拿到 Pages 链接的人可读 |

结论：**介意数据外露就用 Private + Pages 链接看**；想「本地文件直接读云端」就必须 Public（或自己加一层带鉴权的 Worker 代理）。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| Actions 报登录失败 `code=001` | Secrets 里账号密码填错/没填 |
| 报飞书 91403 | `FEISHU_APP_SECRET` 不对，或应用没发布 |
| 报青鸾接口连不上（超时） | 少数情况下青鸾会拦境外 IP；这时改用国内云函数（阿里云 FC / 腾讯云 SCF），工程不用改 |
| 页面 404 | Cloudflare 项目名和 `CLOUDFLARE_PROJECT_NAME` 不一致 |
| 提交那步报 403 / `remote: Permission denied` | workflow 顶部要有 `permissions: contents: write`（默认只有 read，不够 push） |
| 本地页面一直显示「内置快照」 | ①没填 `config.json` 的 `publish`（owner/repo）且没重新构建；②仓库是 Private；③`file://` 直开被浏览器拦了 fetch，改用 `打开地图.bat` |
| 想换时间 | 改 `.github/workflows/daily.yml` 里 `cron: "10 18 * * *"`（UTC，+8 小时才是北京时间） |
| 不想注册 Cloudflare | 用 GitHub Pages：仓库改成 Public，把 workflow 里发布步骤换成 `actions/deploy-pages`。**注意仓库公开 = 18 条客户信息公网可见** |

## 和本机定时任务的关系

云端跑起来后，本机的 `定时任务启动.bat` 就不需要常开了。两者同时开会对飞书表重复写一遍——能跑但没必要。想保留本机看地图（离线快照）就继续用，只是数据会比云端晚。
