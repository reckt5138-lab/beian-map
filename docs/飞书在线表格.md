# 飞书在线表格：接入方式与排错

每次导出后，脚本会把同一张在线表格的「备案项目」工作表**整表覆盖**成最新数据（行数变少会补空行清掉旧数据），不是每次新建文件。「导出说明」工作表同步刷新。

| 模式 | `feishu.auth_mode = "app"` |
| 应用 | `App ID = cli_ab8ae3e157f9dc01`（企业自建应用「青鸾项目导出」） |
| 表格 | 应用自建：`https://jcntthw4tzwh.feishu.cn/sheets/E1AcsZQ2EhT6Vgt9GiHcxmp6ncc`（标题「备案项目每日导出」） |
| 密钥 | `feishu.app_secret` 放在 `config/credentials.json`，不在 config.json 里 |

为什么用应用自建的表：应用空间的表归应用所有，写入不需要人工加协作者；放在用户空间会被跨租户权限拦住（`91403 Forbidden`）。这张表不在个人「我的空间」里，用链接直达，或在网页「··· / 分享」里「添加到我的空间 / 收藏」。

## 方式一：应用身份（app，推荐无人值守）

1. 用持有目标表的账号登录 <https://open.feishu.cn/app>，创建企业自建应用。
2. 「凭证与基础信息」拿 **App ID / App Secret**。
3. 「权限管理」加 `sheets:spreadsheet`、`drive:drive`（个人租户免审，企业租户需管理员审核）。
4. 「版本管理与发布」创建版本并发布。
5. 若要写自己空间里的表：表「分享」→ 添加协作者 → 搜应用名 → 「可编辑」。**应用和表必须在同一企业**。
6. 配置：

```json
"feishu": {
  "enabled": true,
  "auth_mode": "app",
  "app_id": "cli_xxx",
  "app_secret": "",
  "url": "https://xxx.feishu.cn/sheets/Shtxxxxxxxx",
  "spreadsheet_token": "",
  "sheet_name": ""
}
```

`app_secret` 建议只放 `config/credentials.json`（字段 `feishu_app_secret`）或环境变量 `FEISHU_APP_SECRET`。
`spreadsheet_token` 留空会从 `url` 解析；`sheet_name` 留空就写第一张工作表。

7. 验证：`python app\crawler.py --feishu-check`，能看到 `tenant_access_token 获取成功` + 工作表列表即通。

脚本自动处理的两个飞书限制：

- 新表默认 20 列，写 158 列报 `90202 RangeVal fail` → 写前自动扩行扩列。
- v2 写值接口单次约 100 列宽上限 → 按 100 列分块写。

## 方式二：lark-cli 登录态

```json
"feishu": { "enabled": true, "auth_mode": "lark_cli", "lark_cli_profile": "" }
```

用本机 lark-cli 当前登录账号（或指定 profile）写表。首次运行会 `+workbook-import` 导入成在线表并回写 token。依赖登录态，环境重置后需重新登录，不适合长期无人值守。

## 换表 / 关闭同步

- 换表：把 `feishu.spreadsheet_token`、`sheet_id` 清空，填新表 `url`，下次运行自动重新定位；`folder_token` 可指定创建位置。
- 关闭：`feishu.enabled=false`，或单次 `python app\crawler.py --no-feishu`。

## 常见错误

| code / 现象 | 原因与处理 |
| --- | --- |
| `91403 Forbidden` | 跨租户或应用没有该表编辑权；改用应用自建表，或把应用加为协作者 |
| `90202 RangeVal fail` | 一次写的列宽超过限制；脚本已自动扩列 + 分块，若仍出现检查 `checkin_columns` |
| `90215 sheetId not found` | sheet_id 过期或工作表被改名/删除；清空 `sheet_id` 重跑 |
| 链接打不开 | 表在应用空间；用链接直达，或确认 `link_share` 至少为租户内可读 |
