# 部署说明

版本：V3.0　最后更新：2026-11-22

## 一、组成

| 部分 | 位置 | 说明 |
|---|---|---|
| 定时抓取 + 发布 | `.github/workflows/daily.yml` | 每天北京时间 02:10，也支持手动触发 |
| 校验 | `.github/workflows/deploy.yml` | 只跑编译 + 测试 + 敏感检查，不发布 |
| 主站 | GitHub Pages | `https://reckt5138-lab.github.io/beian-map/` |
| 备用站 | Cloudflare Pages（可选） | 未配 Token 时该步骤自动 skipped |
| 发布目录 | `dist/` | 只放 `index.html` 与脱敏 `data.json` |

## 二、GitHub 配置

1. 仓库：`reckt5138-lab/beian-map`，分支 `main`
2. Settings → Pages → Source = **GitHub Actions**
3. Settings → Actions → General → Workflow permissions = Read and write（供 `GITHUB_TOKEN` 提交）
4. Settings → Secrets and variables → Actions：

| Name | 必需 | 用途 |
|---|---|---|
| `JUFA_USERNAME` | 是 | 青鸾账号 |
| `JUFA_PASSWORD` | 是 | 青鸾密码 |
| `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID` / `CLOUDFLARE_PROJECT_NAME` | 否 | 备用站 |

## 三、首次部署（菜单 1）

`青鸾地图.bat` → 1 → `scripts/first_setup.py`：检查 Python/Git/网络 → 建 `.venv` → 装依赖 → 收集账号写 `config/credentials.json` → 真登录验证 → 试抓一次 → 校验 → 提示 Secrets 填写。

仓库创建与推送走 `scripts/deploy_github.py`（建库 → 推代码 / API 逐文件推送 → 写 Secrets → 触发 Actions）。不会强推、不会改写远端历史。

## 四、一键更新（菜单 2）

`scripts/deploy_update.py`：编译检查 → 测试 → 敏感文件扫描 → 部署预览 → 有意义的 commit → **GitHub Contents API 推送** → 触发 Actions → 打印站点地址。

- 无实际改动：不产生空提交
- 检测到完整业务数据可能公开：中止并说明
- 永不 `--force`

## 五、手动刷新（菜单 3）

`scripts/refresh.py`：触发 `daily.yml` → 查运行状态 → 打印 Actions 地址。只刷数据，不改代码。

## 六、Cloudflare Pages（可选）

CF 控制台 → Workers & Pages → Create → Pages → Connect to Git → 选仓库；框架 None，构建命令空，输出目录 `dist`；再配三个 Secret。未配置时 `daily.yml` 里该步骤 skipped。

## 七、抓数与发布的关系

`daily.yml` 抓数后只写 runner 临时目录的完整 JSON，脱敏后产出 `dist/index.html` + `dist/data.json` 并上传 Pages 产物；仓库里不出现 158 列数据。抓取或校验失败则不再提交，线上继续是上一版。

## 八、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 登录失败 | 账号错/风控/Secret 拼错 | 网页登录验证；检查 Secrets 无空格 |
| 抓取 0 条 | 青鸾改版或筛选不匹配 | 看 `output/raw/` 原始响应 |
| 分页不完整 | `max_pages` 触顶 | 提高上限或缩小 `status_filter` |
| 数据骤降被阻断 | 今日 < 上一版阈值 | 核对日志，确认后人工调整阈值 |
| `git push` 超时 / schannel 报错 | 本机 TLS 不稳 | 用菜单 2（API 推送） |
| Actions 红灯 | 抓取失败/校验阻断/权限不足 | 看第一个失败步骤 |
| Pages 404 | Source 未设 GitHub Actions | Settings → Pages 改正 |
| Actions 绿但数据没变 | 数据无变化，按设计不提交 | 正常；要强制发布就手动 Run workflow |
| 页面显示「云端数据加载失败」 | `dist/data.json` 缺失或发布失败 | 看 Pages 部署步骤与 `dist/` 内容 |
| 地图打不开 | 端口占用 | 自动换端口，按打印地址访问 |
