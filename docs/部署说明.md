# 部署说明

版本：V2.1 Lite 　最后更新：2026-11-21

## 一、组成

| 部分 | 位置 | 说明 |
|---|---|---|
| 定时抓取 + 发布 | `.github/workflows/daily.yml` | 每天北京时间 02:10，也支持手动触发 |
| PR/手动校验 | `.github/workflows/deploy.yml` | 只跑编译+测试+敏感检查，不发布 |
| 主站 | GitHub Pages | `https://reckt5138-lab.github.io/beian-map/` |
| 备用站 | Cloudflare Pages（可选） | 未配 Token 时该步骤自动 skipped |
| 构建目录 | `dist/` | 只放 `index.html` 与脱敏 `data.json` |

## 二、GitHub 配置

1. 仓库：`reckt5138-lab/beian-map`，分支 `main`
2. Settings → Pages → Source = **GitHub Actions**
3. Settings → Actions → General → Workflow permissions = Read and write（供 `GITHUB_TOKEN` 提交）
4. Settings → Secrets and variables → Actions 新增：

| Name | 必需 | 用途 |
|---|---|---|
| `JUFA_USERNAME` | 是 | 青鸾账号 |
| `JUFA_PASSWORD` | 是 | 青鸾密码 |
| `PUSH_TOKEN` | 否（工作流用内置 token） | 本机 API 推送用，不配也不影响云端 |
| `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID` / `CLOUDFLARE_PROJECT_NAME` | 否 | 备用站 |

## 三、首次部署（菜单 1）

`青鸾地图.bat` → 1 → `scripts/first_setup.py`：

检查 Python/Git/网络 → 建 `.venv` → 装依赖（`requirements.txt`）→ 收集账号写 `config/credentials.json` → 真登录验证 → 试抓一次 → 校验 → 提示 Secrets 填写地址。

不会创建仓库、不会强推、不会改写远端历史。

## 四、一键更新（菜单 2）

`scripts/deploy_update.py`：编译检查 → 35 项测试 → 敏感文件扫描 → 部署预览 → 有意义的 commit → **GitHub Contents API 推送**（绕开本机 `git push` 的 TLS 抖动）→ 触发 Actions → 打印站点地址。

- 无实际改动：不产生空提交，询问是否只刷新数据
- 检测到完整业务数据可能公开：中止并说明
- 永不 `--force`

## 五、手动刷新（菜单 3）

`scripts/refresh.py`：检查 `gh` → 触发 `daily.yml` → 查运行状态 → 打印 Actions 地址。只刷数据，不改代码。

## 六、Cloudflare Pages（可选）

CF 控制台 → Workers & Pages → Create → Pages → Connect to Git → 选仓库；框架 None，构建命令空，输出目录 `dist`；再配上面三个 Secret。未配置时 `daily.yml` 里该步骤为 skipped，不影响主站。

## 七、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 登录失败 | 账号错/风控/Secret 拼错 | 网页登录验证；检查 Secrets 无空格 |
| Token 过期中断 | 长任务 | 已内置重登；仍失败减小 `crawl.page_size` |
| 抓取 0 条 | 青鸾改版或筛选不匹配 | 看 `output/raw/` 原始响应 |
| 分页不完整 | `max_pages` 触顶 | 提高上限或缩小 `status_filter` |
| 数据异常下降被阻断 | 今日 < 上一版 60% | 核对日志数字，确认后人工调整阈值/快照 |
| Excel 生成失败 | 文件被 Excel 占用 | 关闭已打开文件重跑 |
| `git push` 超时 / `schannel: server closed abruptly` | 本机 TLS 不稳 | 用菜单 2（API 推送） |
| Actions 红灯 | 抓取失败/校验阻断/权限不足 | 看第一个失败步骤 |
| Pages 404 | Source 未设 GitHub Actions | Settings → Pages 改正 |
| 数据不更新但 Actions 绿 | 数据无变化，按设计不提交 | 正常；要强制发布就手动 Run workflow |
| CF 步骤 skipped | 未配 Token | 预期行为 |
| 地图打不开 | 端口占用 | 自动换端口，按打印地址访问 |
